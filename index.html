About

I am a machine learning researcher and M.S. Software Engineering candidate at Hohai University, advised by Prof. Ping Ping. My work sits at the meeting point of computer vision and security, with a focus on robust image protection, generative model attacks, and evaluation frameworks for real-world AI systems.

To run that work rigorously, I built a multi-model research platform that coordinates several local and remote language models and evaluates watermarking schemes at scale, across more than one hundred thousand generated and attacked images.

Projects

InvisibleWatermarkLab

Multi-agent AI research platform for invisible-watermark robustness research

  • Orchestrates multiple local and remote language models with task-based routing behind a FastAPI backend and a React frontend.
  • Evaluates watermarking defenses under adversarial attack settings, diffusion-based reconstruction, and geometric perturbations.
  • Supports large-scale GPU experiments using automated pipelines for evaluation, logging, and analysis.

Stack: Python, FastAPI, PyTorch, Diffusers / Transformers, React, TypeScript, Vite, MCP

AutoLabler

AI-powered full-stack image-annotation tool

  • FastAPI backend with a React labeling canvas, unifying multiple vision models behind one API with dynamic GPU management.
  • One-click auto-labeling and interactive segmentation with export support across common annotation formats.

Stack: Python, FastAPI, React, PyTorch, Ultralytics YOLO, SAM / SAM2, DINOv3, Docker

FootballVision

Automated football-match analysis pipeline

  • Custom-trained YOLOv5 for player, ball, and referee detection tuned for football-specific scenes.
  • Per-player tracking with team assignment, camera-motion compensation, and possession tracking in a CLI and Streamlit app.

Stack: Python, YOLOv5, Ultralytics, OpenCV, NumPy, Pandas, Streamlit
